用上面的定义做一致性核对（这是算术说明，不是新的测量）：

```
9.80665 × 0.200008854 = 1.961416828…  ≈  1.96141684 N
```

与记录给出的 `1.96141684` N 在该记录位数上一致。同一条记录还写明：该力在同实例 `FixedUpdate` 的 `AddForceAtPosition` 调用位置被记录到，随后显式归零生效。

2026-11-25 测试场景 CSV 在同一输入 `0.12` 处打印的 `forceReq` 为 `1.961417` N，与历史求值 `ThrusterAsset` T200-V16 `Evaluate(0.12) * 9.80665 = 1.96141684` N 在六位小数上一致。这是本机实测核对，不替换上表的历史调试来源，也不提供完整 *C*(*u*) 曲线。

> 精度与动力学界限
