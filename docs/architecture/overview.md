## 项目分类

不要把原版能力、环境配置、适配修改和未来自研混写成同一类"已完成工作"。

| 类别 | 指什么 | 当前怎么记 |
| --- | --- | --- |
| 原版能力 | MARUS 已提供的场景、推进器、控制器、传感器、本地键盘等 | 作为复用基线；最小闭环中的连接、求值与施力调用、本地键盘已有历史验证，速度 / 位移已在 2026-11-25 测试场景记录到。不能把局部路径写成整船动力学已完成 |
| 环境配置 | Ubuntu 24.04、Unity 6000.5.11f1、ROS 2 Jazzy、适配器监听环境变量配置等 | 基础环境与工程获取已完成；渲染资产与许可证不代表已全部验收 |
| 适配修改 | 以 `marus2_ros_adapter` 为主的 ROS 2 桥接；Unity 侧 `RosConnection` 是 gRPC 连接层 | 连接与 GPS 消息传输已有历史验证；不属于"改了原版推进器公式" |
| 未来自研 | 自有动力学、传感器、控制模块，以及训练、测试与实艇接口 | 未开始。Hybrid ECS 仅是未决候选，不写入已锁定架构 |

2026-11-25 测试场景运动验收的证据、边界和文件索引见 [已有验证结果 §阶段 1 测试场景运动验收]({% link docs/operations/verification.md %}#阶段-1-测试场景运动验收)。

## 新手术语解释

| 术语 | 说明 |
|:-----|:-----|
| **gRPC** | Unity（`RosConnection`）与 ROS 适配器之间的远程调用协议 |
| **FixedUpdate** | Unity 按物理步进调用的更新函数，推进力在此经 `AddForceAtPosition` 施加 |
| **NavSatFix** | ROS 常用卫星定位消息；已验证的是消息可达，不是精度或坐标约定 |
| **Transform** | 位置与朝向（本地键盘直接改它） |
| **Rigidbody** | 刚体（推进器路径的终点） |

{: .note }
以上术语解释基于当前复用基线的技术栈，不代表最终架构锁定。

## 推进力单位与施力关系

下面给出**教学用的单位定义**。推进力计算公式为标准 kgf→N 换算，系数 9.80665 来自标准单位换算 1 kgf = 9.80665 N（对应标准重力加速度 9.80665 m/s²），**不是本项目拟合得到的系数**。

*C*(*u*) 为推进器曲线输出，记录单位是千克力（kgf）；*F*<sub>N</sub> 为换算后的牛顿（N）。当前也没有完整的 *C*(*u*) 曲线表达式，历史验证数值见 [已有验证结果]({% link docs/operations/verification.md %}#历史验证数值)。2026-11-25 测试场景 CSV 在同一输入点再次记录到请求推力 1.961417 N，与历史值在六位小数上一致；这是本机实测核对，不是新的曲线拟合，也不能写成动力学已验证。
