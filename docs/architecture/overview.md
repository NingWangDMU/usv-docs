## 项目分类

不要把原版能力、环境配置、适配修改和未来自研混写成同一类"已完成工作"。

| 类别 | 指什么 | 当前怎么记 |
| --- | --- | --- |
| 原版能力 | MARUS 已提供的场景、推进器、控制器、传感器、本地键盘等 | 作为复用基线；最小闭环中的连接、求值与施力调用、本地键盘已有历史验证，速度 / 位移已在 2026-11-25 测试场景记录到。同日晚间又记录了多档前向、左右单侧、艏侧与对称倒车的离散短脉冲。同日 GNSS 核验已记录发布频率、坐标系约定，以及数值正确性无法核验的条件。2026-11-26 至 2026-11-27 又记录了静止条件下的 IMU / LiDAR 话题与默认 `/tf` 边集，并用方案 A 做了未保存的临时根 TF 验证。不能把局部路径或离散短脉冲写成整船动力学已完成或完整推进曲线已验收，也不能写成定位已验收，或 IMU / LiDAR 已标定、官方示例已持久挂载完整 TF 树 |
| 环境配置 | Ubuntu 24.04、Unity 6000.5.11f1、ROS 2 Jazzy、适配器监听环境变量配置等 | 基础环境与工程获取已完成；渲染资产与许可证不代表已全部验收 |
| 适配修改 | 以 `marus2_ros_adapter` 为主的 ROS 2 桥接；Unity 侧 `RosConnection` 是 gRPC 连接层 | 连接与 GPS 消息传输已有历史验证，并在 2026-11-25 GNSS 抽查中再次收到完整 `NavSatFix`；2026-11-27 又确认 IMU、LiDAR 与 `/tf` 均由该适配器发布。不属于"改了原版推进器公式"，也不等于精度已通过 |
| 未来自研 | 自有动力学、传感器、控制模块，以及训练、测试与实艇接口 | 未开始。Hybrid ECS 仅是未决候选，不写入已锁定架构 |

## 新手术语解释

| 术语 | 说明 |
|:-----|:-----|
| **gRPC** | Unity（`RosConnection`）与 ROS 适配器之间的远程调用协议 |
| **FixedUpdate** | Unity 按物理步进调用的更新函数，推进力在此经 `AddForceAtPosition` 施加 |
| **NavSatFix** | ROS 常用卫星定位消息。已验证消息可达；2026-11-25 还记录了发布频率与坐标系约定，以及数值正确性无法核验的条件。这不是定位已验收 |
| **Imu / PointCloud2 / TFMessage** | 2026-11-27 已在测试场景中核对这些话题的类型与发布关系。IMU 消息头时间戳为 25.000 Hz（设定 100 Hz），LiDAR 为 10.000 Hz（与设定相符）。这不是标定或精度验收 |
| **Transform** | 位置与朝向（本地键盘直接改它） |
| **Rigidbody** | 刚体（推进器路径的终点） |

{: .note }
以上术语解释基于当前复用基线的技术栈，不代表最终架构锁定。

## 推进力单位与施力关系

下面给出**教学用的单位定义**。推进力计算公式为标准 kgf→N 换算，系数 9.80665 来自标准单位换算 1 kgf = 9.80665 N（对应标准重力加速度 9.80665 m/s²），**不是本项目拟合得到的系数**。

*C*(*u*) 为推进器曲线输出，记录单位是千克力（kgf）；*F*<sub>N</sub> 为换算后的牛顿（N）。当前也没有完整的 *C*(*u*) 曲线表达式，历史验证数值见 [已有验证结果]({% link docs/operations/verification.md %}#历史验证数值)。2026-11-25 测试场景 CSV 在同一输入点再次记录到请求推力 1.961417 N，与历史值在六位小数上一致；同日晚间又在 +0.18 / +0.24 / +0.36 / −0.12 与艏侧 +0.24 处做了离散点对照。这是本机实测核对，不是新的曲线拟合，也不能写成完整 *C*(*u*) 或动力学已验证。
