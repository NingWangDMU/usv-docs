## GPS 精度、频率与坐标约定 {#gps-精度频率与坐标约定未验证}

| 项 | 内容 |
| --- | --- |
| 现象 | 2026-11-25 在同一测试场景中已再次收到完整 `NavSatFix`，并记下三项结论。发布频率：Inspector 设定 `SampleFrequency` / `GnssGrpc.UpdateFrequency` 均为 100 Hz，80 条消息的 `header.stamp` 平均间隔约 0.0400 s，对应约 25.000 Hz，与设定不一致；差异原因未拆开验证。墙钟接收频率因 `ros2 topic hz` 不接受 `--no-daemon` 报错即停，没有正式 `hz` 统计。坐标系约定：`frame_id` 为 `marus_boat/gps_frame`，当时原点按纬度 45、经度 15、高度 0 记录；静止样本与 Inspector 的 Point 一致到很高位，这只是同一套换算链的一致性。数值正确性：按当时条件无法核验 |
| 影响 | 不得把话题有消息、协方差全 0、`isRTK` 或 `status` / `service` 枚举，或与同一套 `Unity2Geo` 换算链的互相比对，升级为定位已验收或 GPS 精度已通过。设定值 100 Hz 不是已测到的话题频率。粉色地形与 Vulkan 警告仍存在，不作为本项失败条件 |
| 状态 | 已记录三项结论（本机实测；精度无法核验）。详情与原数见 [已有验证结果 §GNSS / GPS 精度、发布频率与坐标系约定]({% link docs/operations/verification.md %}#gnss-gps-约定核验) |
| 锚点 | 旧标题「GPS 精度、频率与坐标约定未验证」的锚点予以保留，避免既有链接失效 |
